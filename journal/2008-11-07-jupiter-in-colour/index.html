Jupiter in Colour

07 November 2008 · Astrophoto Posts

The first hi-resolution image of Jupiter in colour, using the DKM21 camera. 

Telescope + Camera: 0.35m SCT + DMK21 Using several hundred frames captured through RGB filters using the DMK21 video camera. Each channel is processed separately in Registax, and then combined to produce a colour image.
