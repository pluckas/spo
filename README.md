# Shenton Park Observatory

Shenton Park Observatory is a private astronomical observatory in Western Australia. Its work includes spectroscopy, variable-star photometry, supernova discovery and minor-planet observations.

This website brings together published research, observing notes, equipment records and historical astronomical images.
